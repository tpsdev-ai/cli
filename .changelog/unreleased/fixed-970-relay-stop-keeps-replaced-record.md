- **`tps mail relay stop` compares a relay pid record's bytes before removing it.** At both removal sites the stop reads the record once immediately before signalling, signals only when it still names the same pid and start token, and compares the record's bytes with that read before it unlinks the path; a record a new relay wrote is kept. A kept record that is a verified running relay under a different pid or token is named as belonging to that process; any other record still readable at that check is reported as no longer holding the record this stop read, and the stop exits 0 because the relay it targeted did stop. Relay pid records are written without a lock, so a record written between the compare and the unlink can still be removed. A record that cannot be read at the final check is kept and the stop exits non-zero.
