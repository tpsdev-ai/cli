- **Branch pid records are claimed and removed under one inter-process lock (Closes #730).** When launching a detached daemon, `tps branch init` and `tps branch start` read, classify, spawn and write the record while holding it; `tps branch stop`, daemon shutdown, stale-record replacement and `tps office kill`'s branch-record handling use the same lock. A command that cannot acquire the lock within its timeout refuses, naming the lock path. At a final read, a readable replacement is preserved, an unreadable file or symlink is kept and the removal is refused, and a missing record is reported.
