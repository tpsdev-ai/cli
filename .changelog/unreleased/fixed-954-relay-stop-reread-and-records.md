- **`tps mail relay stop` re-reads the pid record before signalling; `tps office status` classifies the relay record instead of checking that its pid file exists.** Stop signals only a record that is still `running` with the same pid and start token; a record that changed is reported and no process is signalled. `tps bridge status --json` includes a `reason` for an `invalid` record, and for an `unreadable` record that has one. Office status reports `running` only for a running relay record; a stale, unverified, invalid or unreadable record is named.
