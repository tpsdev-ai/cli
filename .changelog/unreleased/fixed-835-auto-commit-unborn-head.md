- **Mail tasks can commit changes on an unborn HEAD.** An unborn HEAD whose task leaves changes is committed as that branch's first commit when no aborted rebase restored a HEAD different from the final HEAD and the commit command succeeds. An empty `git status --porcelain` with no new commit counts as clean only when the pre-task and final HEAD probes and the status probe succeed and any interrupted rebase was aborted; an indeterminate probe or a failed rebase abort is reported and skipped. "Workspace changes" means what `git status --porcelain` reports, not ignored files. An unborn HEAD is a branch with no commit yet; the repository may have other branches.
