- **The first changes from a mail task in a repository with no commits are committed when the HEAD probes succeed and the commit command succeeds.** An unborn repository whose task leaves changes is committed as its first commit when no aborted rebase restored a different HEAD and the commit command succeeds. An empty `git status --porcelain` with no new commit counts as clean only when the pre-task and final HEAD probes and the status probe succeed and any interrupted rebase was aborted; an indeterminate probe or a failed rebase abort is reported and skipped. "Workspace changes" means what `git status --porcelain` reports, not ignored files. An unborn HEAD is a branch with no commit yet; the repository may have other branches.
