- **A relative `workspace` in `agent.yaml` resolves against the config file's directory, and a launched child receives the absolute path.** An absolute workspace remains absolute and is normalized. A `workspace` or `repo` string starting with `~` is refused, because `~` is not expanded, and so is a `workspace` or `repo` key whose value is null (in YAML a bare `~` or nothing after the key), not a string, or an empty or blank string. For the native AgentRuntime, default `mailDir` and `memoryPath` derive from the resolved workspace (Closes #658).
