- **Guard relay claims after the first attempt with record ownership and process liveness.** On the first claim attempt, the connection attempts a write without an ownership check, only while the stop gate is open; it can replace an invalid file. A claim after that attempt checks eligibility only while the stop gate is open, and attempts the write when the record is absent, is verified as owned by this connection, or belongs to a connection whose recorded process is not running or is running with a start token different from the recorded one (pid reuse). A record whose token was altered is indistinguishable from pid reuse. On claims after the first attempt, an invalid, unreadable or unverifiable record is left as it is; the claim reporter emits one diagnostic line for an ownership or readability refusal, and a later refresh may report separately.
