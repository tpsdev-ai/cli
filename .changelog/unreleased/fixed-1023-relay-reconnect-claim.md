- **A relay reconnect reclaims the host state record only when its recorded process is not running or has a different start token (pid reuse).** The first claim of a connection still writes the record; a later claim writes when the record is absent, carries this connection's own id, or meets that condition — the recorded process is not running, or is running with a start token different from the recorded one. A record whose token was altered is indistinguishable from pid reuse. An invalid, unreadable or unverifiable record is left as it is, and an ownership or readability refusal is reported in one diagnostic line.
