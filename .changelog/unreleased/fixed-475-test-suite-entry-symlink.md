- **`scripts/test-suite.mjs` and `scripts/check-test-reports.mjs` start when invoked through a symlinked path.** They compared `process.argv[1]` as given against `import.meta.url`, which is resolved through symlinks, so through a symlinked path (on macOS `/var/...` is a symlink to `/private/var/...`) the launcher exited 0 having run no suite, and the guard exited 0 having printed no report.
