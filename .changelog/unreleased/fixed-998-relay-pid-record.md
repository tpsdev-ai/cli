- **`tps mail relay start` refuses an invalid relay pid record and claims the record path exclusively.** An invalid record is kept and the start exits non-zero naming the path and the remedy; a stale record is replaced. Between the exclusive claim and the daemon's own write the record names the starting process, which `relay status` reports as a start in progress and `relay stop` does not signal. The daemon writes its record through a temporary file in the same directory and a rename, and on exit removes it when the file still holds its own bytes, compared under the record lock.
