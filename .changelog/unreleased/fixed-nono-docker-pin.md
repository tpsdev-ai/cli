- Pin the Docker image's nono install to the immutable commit behind tag v0.74.0 (`commit=` in `.nono-version`, verified via `git rev-parse HEAD`), replacing the unpinned default-branch clone (cli#341).
- **Contract the image is now built to satisfy:** the shipped `nono` bytes come only from the pinned `nono-builder` commit. `nono-builder` records the sha256 of the binary it built at the asserted commit; the runtime stage copies that hash in and its **last instruction** re-hashes `/usr/local/bin/nono` and fails the *build* if the two differ — so no `RUN`, `ADD`, fetch tool, secondary stage, path spelling or variable can substitute bytes for the shipped path (cli#341).
- The runtime stage no longer carries a fetch tool at all: `git`, `curl`, `wget`, `python3`, `perl`, `openssl`, `nc`, `socat`, `php` and the system `ca-certificates` bundle (it hard-depends on `openssl`) are gone; `jq` stays (the supervisor uses it) and `node` stays (the agent needs it) (cli#341).
