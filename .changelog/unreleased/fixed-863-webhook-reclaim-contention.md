- **A webhook delivery that races a lock reclaim retries instead of failing closed.** An unreadable owner record whose sampled directory identity changed before the re-check is retried; a live owner in another process on that retry reports `duplicate in progress`. A live owner in the same process still raises `MailLockOwnerError`, which the webhook returns as a 503 naming the lock path, and a stable unreadable owner still fails closed with its named lock path (Closes #863).
