- **The Docker integration image builds the repository's pinned Bun instead of a floating tag (Closes #578).** `Dockerfile.test` takes the version as a required `BUN_VERSION` build arg and its base stage is `FROM oven/bun:${BUN_VERSION}-slim`; `docker-compose.yml` forwards the arg and the Docker Integration workflow derives it from `package.json`'s `packageManager`. `scripts/check-bun-pin.sh` fails the build when those disagree or the arg is absent.
