- **The workflow npm guard reads `shell:` and restricts command-word shapes.** Step `shell:` overrides job defaults, which override workflow defaults; a non-`bash` shell refuses an unapproved run block, naming its source line. For command words selected in workflow steps, leading assignments and redirections are skipped, and words containing `*`, `?`, `[` or `$'` are refused, except `[` and `[[` themselves; the existing `case` handling remains. This is a best-effort lint; variable or substitution indirection and composite-action shells are not covered.
