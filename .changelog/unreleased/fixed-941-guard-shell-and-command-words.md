- **The workflow npm guard reads `shell:` and restricts command-word shapes.** Step `shell:` overrides job defaults, which override workflow defaults; a non-`bash` shell refuses an unapproved run block, naming its source line. A leading redirection or an assignment containing `<` or `>` before a command word refuses an unapproved run block. Command words containing `*`, `?`, `[` or `$'` are refused, except `[` and `[[` themselves; `case` in command position is refused in unapproved run blocks. This best-effort lint does not model compound commands; variable or substitution indirection and composite-action shells are not covered.
