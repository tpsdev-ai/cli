- **The workflow npm guard reads `shell:` and refuses spelled command words.** It reads `shell:` at the workflow, job and step level and refuses a step whose effective shell is not `bash` unless its run block is a pinned entry, and it refuses an ANSI-C-quoted or glob-spelled command word in a run block that is not pinned. Both are best-effort checks for plainly spelled installs: variable or substitution indirection, a glob character inside a quoted word, and anything a non-default shell would interpret are not covered.
