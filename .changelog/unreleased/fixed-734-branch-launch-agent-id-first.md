- **`tps branch start` and a production `tps branch init` report a running recorded process before a missing branch agent id (Closes #734).** With a branch daemon running and recorded, a start or a production re-init (`--force`) with no `TPS_AGENT_ID` and no persisted `agentId` refuses naming the running pid, the pid file and the `tps branch stop` remedy. When the command starts a daemon it checks the recorded process first and resolves the agent id only when that record is not running; with no id configured it refuses by name. A production init refuses before writing the keypair or the conf and before joining.
