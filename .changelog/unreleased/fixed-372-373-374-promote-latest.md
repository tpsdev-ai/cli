- **Promotion locking, npm timeouts, and combined SemVer suffixes.** `promote-latest.sh` serializes runs and bounds each npm call by `NPM_TIMEOUT_SECONDS`, then a 2-second TERM grace before KILL. Handled exits and catchable signals release the lock (SIGKILL cannot run the EXIT trap); a timed-out mutating call leaves the run uncertain, keeps the lock with a reason file, and exits 7. The lock refusal prints the holder's PID, or `unknown` if it reads the directory before the `pid` file is written. The version check accepts prerelease plus build metadata.
