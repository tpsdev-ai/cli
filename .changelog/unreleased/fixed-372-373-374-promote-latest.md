- **Promotion locking, npm timeouts, and combined SemVer suffixes.** `promote-latest.sh` serializes runs with a repo-local lock. Each npm call runs under a small Node supervisor whose deadline is `NPM_TIMEOUT_SECONDS` plus a 2-second TERM grace, measured from the call's start; on expiry it sends TERM, then KILL. Handled exits and catchable signals release the lock, while SIGKILL cannot run the EXIT trap. A timed-out mutating call leaves the run uncertain, keeps the lock, and exits 7; it writes a reason file when it can, and otherwise says the reason could not be written. The lock refusal prints the holder's PID, or `unknown` if the `pid` file is absent. The version check accepts prerelease plus build metadata.
