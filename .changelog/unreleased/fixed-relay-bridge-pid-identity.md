- **Relay and bridge pid files record the process start token, which a stop checks immediately before signalling; a mismatch is refused.** A pid can still be reused between that check and the signal, and the `ps` fallback compares start time only to the second. A stale record is removed; a record whose live pid cannot be verified is refused with the pid file named, and an EPERM from the stop signal keeps the file and exits non-zero. `bridge stop` classifies both known pid files before acting, keeps an unverifiable record's file, removes records it stopped or proved stale or invalid, and reports a removal only when the unlink succeeded.
