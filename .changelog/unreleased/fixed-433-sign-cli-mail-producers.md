- **CLI-internal producers and `MailClient.sendMail` now sign mail before delivery (Refs #433).** Pulse notifications, topic publish and catch-up, hire onboarding, roster invites, bootstrap introduction and health probe, and branch replies and forwards use the v1 signed envelope. The agent runtime and CLI share strict Ed25519 key parsing and the default two-location resolver. Missing or conflicting keys refuse before topic publication or mail delivery. A recipient still requires a matching Flair principal and passing mailbox policy; the bootstrap health check now proves that decision. Mail received by the agent runtime derives sender and authority only from its verified envelope, with absent trust at the lowest level. The openclaw-tps-mail outbound adapter and channel bridge remain slice B.
