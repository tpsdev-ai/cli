- **mail-watch deduplicates ids across tracked, eligible verified files in `new/`.** Verdicts, retry counts and file associations use observed file identities; replacements retry when that identity changes. Each path retains its last known envelope id across failed scans until the path leaves `new/` or a successful read finds a different or missing envelope id. Consecutive failed per-file attempts stop retries at classification. State is in memory, per watcher process.
