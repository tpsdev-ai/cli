- **A bind error rejects the listen call instead of escaping as an uncaught event, and tests share one port helper.** The WebSocket listeners (`WsNoiseTransport.listen`, `listenForJoinWs`, `listenForHostWs`), the branch service proxies, the OpenClaw bridge adapter and the mock LLM listener reject the call that starts them when the bind fails. After a successful bind, an error reaches that listener's failure path rather than an uncaught event. Tests that start a listener in-process bind port 0 and read the port back; a child that binds ports from config starts through `withPortsRetry`.
