- **A bind error rejects the listen call instead of escaping as an uncaught event, and tests share one port helper.** The WebSocket listeners (`WsNoiseTransport.listen`, `listenForJoinWs`, `listenForHostWs`), the branch service proxies, the OpenClaw bridge adapter and the mock LLM listener reject the call that starts them when the bind fails. After a successful bind, the first error runs that listener's failure path once. The mock LLM logs, and the branch service proxies record in their handles, the port they actually bound, so a start on port 0 reports the real port. A test that starts a listener in-process binds port 0 and reads the port it reports; a test that needs a preselected port for a child process starts it through `withPortsRetry`.
