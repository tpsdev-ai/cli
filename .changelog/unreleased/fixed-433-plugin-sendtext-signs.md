- **The openclaw-tps-mail outbound adapter signs every channel send (Refs #433).** A send the plugin routes to a local mailbox, the outbox, a remote branch or a branch-office sandbox is now a v1 signed envelope from the same signing path `tps mail send` uses. A recipient's `promote()` accepts it only when the recipient can resolve the sender's key and the remaining mailbox checks pass. A sender with no Ed25519 private key is refused by name before anything is written. The reply thread rides inside the signed envelope, and the record no longer carries an unsigned wrapper `replyToId`. The channel bridge's inbound messages remain slice B.
