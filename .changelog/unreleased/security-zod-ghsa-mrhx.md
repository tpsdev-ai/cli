- **The CLI workspace now depends on zod 4.6.7, outside the range of GHSA-mrhx-c7xc-m3w5.** Report defaults, ids, timestamps, records and `Expected string, received …` error text keep their zod 3 behaviour. Two changes are deliberate: `.int()` now requires a safe integer, so a value beyond `Number.MAX_SAFE_INTEGER` may not be the integer that was sent (adjacent integers can collapse to one double), and `z.number()` now refuses `Infinity`.
