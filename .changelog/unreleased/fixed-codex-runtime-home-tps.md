- **The codex runtime resolves its tps executable and fallback SOUL.md under the current HOME.** Auto-commit looks for `$HOME/.tps/bin/tps` on every call, so a runtime whose HOME changes after start-up uses the tps installed there instead of falling back to a `tps` on PATH. The fallback SOUL.md path is resolved the same way by the snapshot writer, the offline boot reader and the runtime's boot notice.
