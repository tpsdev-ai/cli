- **Office supervisor**: `shutdown_children` signals the tracked agents, waits up to `SHUTDOWN_GRACE_SECONDS` (10 s) for them to exit, KILLs and reaps any survivor, clears the tracked list and only then removes the PID file, so a second call signals nothing. A signal that arrives between a launch and the tracking of its PID is deferred until the PID is tracked. The control accepts an EXIT trap only as a whitelist: each operation is a recognised stop (`shutdown_children` or `kill`) or a PID-file removal, and a removal of the PID file by variable or literal path before a stop fails. The seating-loop control covers explicit `exit`/`return` forms, a self-kill (`kill ... $$`, any signal) and calls to supervisor functions that exit, and it refuses a loop containing a multi-line quoted string or heredoc.
