- **The openclaw-github-review test lane runs under the shared HOME-isolation guard (Closes #438).** Its launcher makes the guard's launch-time checks before it creates or deletes anything: the child gets the allowlisted environment, a caller-supplied `--reporter-outfile` is refused, a temp dir or report dir that is or contains an operator home — or a report dir, report, log or seal inside `~/.tps`, `~/.flair`, `~/agents` or `~/.config`, or a symlinked report path — is refused before any delete, and the `~/.tps` metadata diagnostic fails a run that writes the real home. A report directory at or above an operator home, `$HOME` included, is therefore refused before the lane deletes its report, log and seal there. Its test preload uses the shared root check, so a bare `bun test` in that directory is refused like the other lanes.
