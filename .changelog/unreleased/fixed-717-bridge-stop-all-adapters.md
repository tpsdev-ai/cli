- **`bridge stop` stops a bridge started through a discovered adapter name.** It finds `bridge-<adapter>.pid` records whose adapter part is lowercase ASCII letters, plus the legacy `mail-bridge.pid`, instead of only `bridge-openclaw.pid` and `mail-bridge.pid`. A missing run directory has no records; any other error reading it is reported with the path and error code and fails the command. A record that does not exit keeps its pid file and the remaining records are still handled.
