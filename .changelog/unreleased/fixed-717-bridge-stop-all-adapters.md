- **`bridge stop` stops a bridge started by any adapter.** It finds every `bridge-<adapter>.pid` in the run directory plus `mail-bridge.pid`, instead of only `bridge-openclaw.pid` and `mail-bridge.pid`. A missing run directory has no records; any other error reading it is reported with the path and error code and fails the command. A record that does not exit keeps its pid file and the remaining records are still handled.
